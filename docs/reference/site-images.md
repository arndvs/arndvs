# Site images

The share cards, blog heroes, and wireframe placeholders on this site are generated by code. The generators, the style rules, and an agent skill live in the [ai-visuals](https://github.com/arndvs/ai-visuals) repo, not here.

| What                                       | Where in ai-visuals                           |
| ------------------------------------------ | --------------------------------------------- |
| Style rules: palette, fonts, sizes, layout | `rules/site-images.md`                        |
| Color and font tokens                      | `python/site_images/style.py`                 |
| Share cards and blog heroes                | `python/site_images/generate_cards.py`        |
| Wireframe placeholders                     | `python/site_images/generate_placeholders.py` |
| Screenshot cropper                         | `python/site_images/crop_screenshot.py`       |
| Agent skill                                | `.claude/skills/site-images/SKILL.md`         |

## Where the images land in this repo

| Image                   | Path here                                                                |
| ----------------------- | ------------------------------------------------------------------------ |
| Default share card      | `public/images/og-image.jpg`                                             |
| Per-project share cards | `public/og/<slug>.jpg`                                                   |
| Blog heroes             | `scripts/assets/blog-heroes/<post-slug>.jpg`                             |
| MCRDSE placeholders     | `public/projects/mcrdse-commerce/` and `public/projects/mcrdse-content/` |

## Changing an image

Do not edit these files by hand or make a new one in another tool. Change the generator in ai-visuals, then run it with this repo as the target:

```bash
python python/site_images/generate_cards.py --site ../arndvs
python python/site_images/generate_placeholders.py --site ../arndvs
```

Blog heroes go live when `pnpm seed:post-heroes` uploads them to Sanity.

The first-reward journey hero in `scripts/assets/inkind-first-reward/` is the exception. It uses inKind's palette because the post is about inKind, and it is not generated by these scripts.

## Animated visuals

Animated visuals are built in `arndvs/ai-visuals` (`visuals/<name>/`) and copied here with its `tools/publish-to-site.sh`. They live in `public/visuals/<name>/index.html` and are embedded on a case study through the `embed` field of a deep dive:

```ts
embed: { src: "/visuals/<name>/index.html?embed=1", title: "Animation: what it shows" },
```

Don't edit the copies here. Change the source in ai-visuals and publish again.
